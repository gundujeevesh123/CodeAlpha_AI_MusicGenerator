# CodeAlpha AI Music Generator

## Overview

An AI-powered music generation system that learns musical patterns from MIDI files and generates original melodies using Deep Learning and LSTM networks.

## Features

- MIDI Data Processing
- Note & Chord Extraction
- LSTM-Based Deep Learning Model
- AI Melody Generation
- MIDI File Output

## Technologies Used

- Python
- PyTorch
- Music21
- NumPy
- Deep Learning
- LSTM Networks

## Run

```bash
python train.py
python generate_music.py
```
