
FINAL CLASSICAL AI MUSIC GENERATOR

STEP 1:
Open CMD in project folder

STEP 2:
Activate venv

venv\Scripts\activate

STEP 3:
Install libraries

pip install -r requirements.txt

STEP 4:
Run preprocessing

python preprocess.py

STEP 5:
Prepare sequences

python prepare_sequences.py

STEP 6:
Train AI

python train.py

STEP 7:
Generate music

python generate_music.py

FINAL OUTPUT:
generated_music.mid
